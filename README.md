## วิธีเปิดสไลด์แอนิเมชัน

1. กดปุ่ม **Code** > **Download ZIP** แล้วแตกไฟล์
2. ดับเบิลคลิก `week01/index.html` ให้เปิดใน Browser
3. กดลูกศรขวาหรือ Space เพื่อไปต่อ ลูกศรซ้ายเพื่อย้อน พิมพ์เลขหน้าแล้วกด Enter เพื่อกระโดด
